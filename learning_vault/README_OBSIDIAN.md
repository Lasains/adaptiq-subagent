# 📱 Selamat Datang di Vault Belajar Java Mobile!

Vault ini adalah tempat belajar utama kamu yang terhubung langsung dengan **Agent CLI** dan **Subagent Adaptif (Java AdaptiKog)**.

---

## 🗂️ Berkas & Struktur Folder Belajar Kamu:

- 🗺️ **[`SILABUS_DAN_ROADMAP.md`](SILABUS_DAN_ROADMAP.md)**: Peta rencana belajar 3 fase (Fondasi Java ➔ OOP ➔ Mobile App).
1. **`01_Materi/`**  
   Tempat Subagent menaruh materi belajar Java (`.md`). Dilengkapi tabel jejak memori (Trace Table), penjelasan pendek ramah disleksia, dan contoh kode Java.
2. **`02_Catatan_Tanya/`**  
   Tempat kamu menulis hal-hal yang belum kamu pahami dari materi. Cukup tulis pertanyaanmu di sini, lalu suruh Agent CLI untuk membaca dan menjelaskannya lagi dengan cara yang lebih mudah!
3. **`03_Jawaban_Kuis/`**  
   Tempat kamu mengetik jawaban kuis atau tantangan logika. Agent CLI akan mengevaluasi jawabanmu dari berkas ini.

## 🚀 Alur Kerja Belajar (Loop 3 Langkah):
