# 🗺️ Silabus & Roadmap Belajar: Java Menuju Mobile App

> **Target Pembelajar**: Pemula Murni (*Zero-Knowledge*), Disleksia, dan Afantasia  
> **Tujuan Akhir**: Mampu membuat logika aplikasi mobile Android fungsional menggunakan bahasa Java  
> **Status Kurikulum**: ✅ *Telah Dievaluasi Pedagogis (Fondasi Java Murni Diutamakan sebelum Mobile UI)*

---

## 🎯 Mengapa Kita Belajar Fondasi Java Dulu?
Sebelum membangun rumah, kita wajib memasang pondasi semen yang kokoh.  
Sama halnya dengan aplikasi HP: **aplikasi Android dibangun di atas fondasi logika Java**.  

Jika kita langsung melompat ke layar HP tanpa paham cara kerja variabel atau percabangan logika, kita akan mudah bingung saat aplikasi mengalami error. Oleh karena itu, perjalanan belajar kita dibagi menjadi **3 Fase Terarah**:

```
[Fase 1: Logika & Java Murni] ➔ [Fase 2: Pemrograman Objek (OOP)] ➔ [Fase 3: Aplikasi Mobile Android]
```

---

## 📍 Fase 1: Fondasi Logika & Bahasa Java Murni
*Tujuan: Memahami cara kerja komputer mengeksekusi instruksi, menyimpan data, dan mengambil keputusan.*

| Bab | Topik Pembelajaran | Konsep Inti & Analogi Mekanis | Target Keterampilan | Status |
| :---: | :--- | :--- | :--- | :---: |
| **01** | **Instruksi Pertama Komputer** | Program seperti resep masakan urut; fungsi `main` sebagai pintu masuk saklar mesin. | Menjalankan program Java pertama tanpa rasa takut. | ⏳ *Siap Dipelajari* |
| **02** | **Variabel & Wadah Angka (`int`)** | Variabel sebagai kotak kardus berlabel nama penyimpan skor atau jumlah barang. | Menyimpan data angka dan melakukan operasi matematika (`+`, `-`, `*`, `/`). | 🔒 *Terkunci* |
| **03** | **Wadah Teks & Kalimat (`String`)** | Teks wajib diapit tanda kutip `""`; merangkai kata dengan simbol `+`. | Menampilkan pesan sambutan yang dinamis dan fleksibel. | 🔒 *Terkunci* |
| **04** | **Pengambil Keputusan (`if-else`)** | Saklar rel kereta api otomatis; memilih jalur A jika benar, jalur B jika salah. | Membuat program yang bisa menentukan status: *Lulus / Gagal*, *Baterai Penuh / Lemah*. | 🔒 *Terkunci* |
| **05** | **Mesin Pengulang (`for` & `while`)** | Stempel mesin pabrik otomatis; melakukan pekerjaan berulang sampai batas hitungan. | Menghitung otomatis dari 1 sampai 100 tanpa mengetik manual. | 🔒 *Terkunci* |

---

## 🏗️ Fase 2: Pemrograman Berorientasi Objek (OOP)
*Tujuan: Memahami bagaimana Java memodelkan benda-benda di dunia nyata (kunci utama memahami komponen HP).*

| Bab | Topik Pembelajaran | Konsep Inti & Analogi Mekanis | Target Keterampilan | Status |
| :---: | :--- | :--- | :--- | :---: |
| **06** | **Class & Object: Cetakan & Benda** | `Class` adalah cetakan kue waffle; `Object` adalah kue wafel nyata yang sudah tercetak di memori. | Membuat model data sendiri (contoh: objek `Pengguna`, objek `Produk`). | 🔒 *Terkunci* |
| **07** | **Method: Perilaku & Perintah Kerja** | Tombol fungsi pada mesin blender; diberi bahan (parameter), mengeluarkan jus (return value). | Memecah kode rumit menjadi fungsi-fungsi kecil yang rapi dan terorganisir. | 🔒 *Terkunci* |
| **08** | **Penyimpan Banyak Data (`ArrayList`)** | Lemari loker bertingkat; bisa ditambah dan diambil berdasarkan nomor antrean (indeks mulai dari 0). | Mengelola daftar belanjaan, kontak teman, atau riwayat pesan. | 🔒 *Terkunci* |
| **09** | **Pewarisan Karakter (`Inheritance`)** | Kerangka dasar kendaraan yang diturunkan ke Mobil dan Motor. | Memahami mengapa komponen UI Android (`Button`, `TextView`) mewarisi sifat dari `View`. | 🔒 *Terkunci* |

---

## 📱 Fase 3: Jembatan Menuju Aplikasi Mobile Android
*Tujuan: Membawa seluruh logika Java ke layar sentuh HP dan membuat aplikasi nyata.*

| Bab | Topik Pembelajaran | Konsep Inti & Komponen Mobile | Target Keterampilan | Status |
| :---: | :--- | :--- | :--- | :---: |
| **10** | **Anatomi Aplikasi HP: Layar & Logika** | Memisahkan Tampilan (XML/Desain Layar) dengan Otak Logika (Berkas Java). | Memahami cara kerja aplikasi HP menampilkan halaman utama. | 🔒 *Terkunci* |
| **11** | **Label Teks & Input Pengguna** | Objek `TextView` (label tulisan) dan `EditText` (kotak ketik nama/password). | Mengambil teks yang diketik pengguna di layar sentuh HP. | 🔒 *Terkunci* |
| **12** | **Tombol Sentuh & Event Listener** | Tombol `Button` yang mendengarkan ketukan jari (*Click Listener*). | Menjalankan aksi otomatis saat pengguna menekan tombol di HP. | 🔒 *Terkunci* |
| **13** | **Proyek Mini 1: Kalkulator Kasir HP** | Menggabungkan input harga, tombol hitung, dan label total belanja. | Menghasilkan aplikasi kasir mini pertama yang berjalan di HP! | 🔒 *Terkunci* |
| **14** | **Pindah Halaman Aplikasi (`Intent`)** | Pintu lorong penghubung antar ruangan; berpindah dari Halaman Login ke Dashboard. | Membuat navigasi multi-halaman dengan riwayat tombol kembali (*back button*). | 🔒 *Terkunci* |
| **15** | **Proyek Akhir: Aplikasi Catatan Pribadi** | Aplikasi pencatat tugas dengan tombol tambah, daftar tugas, dan hapus tugas. | Portofolio aplikasi Android lengkap pertama buatan Anda sendiri! | 🔒 *Terkunci* |
